# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and select **Report a vulnerability**. Include what you found, how to reproduce it, and what an attacker could do with it.

You should hear back within a week. Please give the fix time to ship before you disclose the problem publicly.

## Scope

In scope: this application's code, including authentication, the per-league access rules, invite and reset links, the importer, and the deployment files in this repository.

Out of scope: any particular server running this code. Don't test against a site you don't own.

## Supported versions

Only the latest `main` branch gets security fixes.
